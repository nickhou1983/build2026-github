02 · AGENTIC

Agentic 能力全面升级

从代码补全助手迈向自主执行的智能 Agent

公开预览

Cloud & Local Sandboxes

Copilot 可在安全隔离的沙箱中运行，支持本地和云端双模式

全新

/agentfinder — 智能 Agent 发现

根据任务上下文自动发现并匹配最合适的 Agent 与 Skill，无需手动检索即可快速调用

全新

/chronicle — 记忆与上下文持久化

Agent 可跨会话记住项目上下文、决策历史和代码架构，持续积累对代码库的深度理解

预览

/fleet — 多 Agent 协同编排

同时调度多个 Agent 并行处理不同任务，协调依赖关系，大幅提升复杂项目的交付效率

智能

AI 辅助合并冲突解决

自动化

Self-Review 自审查

03 · CODE REVIEW

Code Review 重大更新

统一 Agent 平台架构，审查 → 修复 → 合并闭环

公开预览

Agent Skills + MCP 支持

将组织级上下文（工具链、编码标准、MCP 协议）引入每次代码审查，实现更精准、更贴合团队规范的反馈

新增

Medium Analysis Tier

复杂 PR 自动路由到更高推理能力模型进行深度分析，简单变更使用快速模型，实现成本与质量的最优平衡

技术预览
