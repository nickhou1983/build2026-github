02 · AGENTIC

Agentic 能力全面升级

从代码补全助手迈向自主执行的智能 Agent

公开预览

Cloud & Local Sandboxes

Copilot 可在安全隔离的沙箱中运行，支持本地和云端双模式

安全

MXC 进程隔离

CLI 采用 MXC 沙箱约束动态生成代码的执行范围，防止越权操作

全新

/chronicle — 记忆与上下文持久化

Agent 可跨会话记住项目上下文、决策历史和代码架构，持续积累对代码库的深度理解

预览

/fleet — 多 Agent 协同编排

同时调度多个 Agent 并行处理不同任务，协调依赖关系，大幅提升复杂项目的交付效率

智能

AI 辅助合并冲突解决

智能分析冲突上下文，减少手动处理合并冲突的工作量

自动化

Self-Review 自审查

Agent 提交 PR 前自动对自身代码进行审查并修复发现的问题

03 · CODE REVIEW

Code Review 重大更新

统一 Agent 平台架构，审查 → 修复 → 合并闭环

公开预览

Agent Skills + MCP 支持

将组织级上下文（工具链、编码标准、MCP 协议）引入每次代码审查，实现更精准、更贴合团队规范的反馈

新增

Medium Analysis Tier

复杂 PR 自动路由到更高推理能力模型进行深度分析，简单变更使用快速模型，实现成本与质量的最优平衡

技术预览

Copilot Code Review for Azure Repos

直接在 Azure DevOps 的 Pull Request 中请求 Copilot 代码审查，无需切换到 GitHub 平台
